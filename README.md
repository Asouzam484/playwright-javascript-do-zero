# 🎭 Playwright + JavaScript do Zero

Este repositório acompanha a minha aprendizagem prática de JavaScript e Playwright.

O objetivo é aprender desde os fundamentos de JavaScript, praticando cada conceito, até conseguir criar e compreender testes automatizados com Playwright.

## 📚 Progresso dos estudos

### ✅ Dia 1 — Fundamentos de JavaScript

- Variáveis
- `const` e `let`
- String, Number e Boolean
- Comparações
- `if` e `else`

### ✅ Dia 2 — Funções e operadores lógicos

- `&&` — E
- `||` — OU
- Funções
- Parâmetros
- Argumentos
- `return`

### ✅ Dia 3 — Arrays, objetos e loops

- Objetos `{ }`
- Propriedades
- Arrays `[ ]`
- Índices
- Arrays de objetos
- `for...of`
- Combinação de `for` + `if`

### 🚧 Dia 4 — Async/Await

- `async`
- `await`
- Operações que precisam de espera
- Preparação para Playwright

## 🎯 Objetivo

Construir uma base sólida de JavaScript para evoluir gradualmente para automação de testes com Playwright.

## 🛠️ Tecnologias

- JavaScript
- Node.js
- Git
- GitHub
- Playwright
